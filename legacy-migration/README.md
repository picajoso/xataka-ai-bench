# Resultados históricos

Este directorio describe cómo se interpretan los nombres de las carpetas del
archivo histórico. El inventario y una futura importación trabajan en modo de
solo lectura sobre el origen: no reescriben proyectos, repositorios anidados
ni archivos generados.

Los resultados importados se etiquetarán como `legacy-unverified` hasta que
se revisen individualmente. La ausencia de duración, coste o versión exacta
no se rellena por inferencia: se conserva como dato desconocido.
